# Chapter 1: JavaScript/TypeScript 基礎

## 🎯 学習目標

- JavaScript の基本文法を理解する
- TypeScript で型付けする方法を習得する
- モダンな JavaScript の記法（ES6+）を使いこなす

## 📚 学習トピック

### 1.1 変数定義

- `var`, `let`, `const` の違い
- スコープ（ブロックスコープ、関数スコープ）
- 変数の巻き上げ（hoisting）

**TypeScript での型付け:**
- 基本的な型アノテーション
- 型推論

### 1.2 関数

- 関数宣言 vs 関数式
- アロー関数
- デフォルト引数、可変長引数

**TypeScript での型付け:**
- 引数の型
- 戻り値の型
- オプショナル引数

### 1.3 制御構文・式

- `if`, `switch`, `for`, `while`
- 三項演算子
- 厳密な等価性（`===` vs `==`）
- Nullish 合体演算子（`??`）
- オプショナルチェーン（`?.`）
- 論理演算子（`&&`, `||`）

### 1.4 分割代入

- 配列の分割代入
- オブジェクトの分割代入
- デフォルト値
- ネストした分割代入

### 1.5 Spread演算子 / Rest構文

- 配列のSpread
- オブジェクトのSpread
- Restパラメータ

### 1.6 変数の型

**プリミティブ型:**
- `string`, `number`, `boolean`
- `null`, `undefined`
- `symbol`, `bigint`

**オブジェクト型:**
- `object`, `array`, `function`
- 参照と値のコピー

**TypeScript の型システム:**
- リテラル型
- ユニオン型
- インターセクション型
- 型エイリアス（`type`）
- インターフェース（`interface`）
