# 💡 Examples / サンプルコード

このディレクトリには、各章の学習内容を理解するためのサンプルコードが含まれています。

## 📁 ディレクトリ構成

```
examples/
├── 01-js-ts-basics/         # Chapter 1のサンプルコード
├── 02-array-object/         # Chapter 2のサンプルコード
├── 03-dom-manipulation/     # Chapter 3のサンプルコード
├── 04-react-fundamentals/   # Chapter 4のサンプルコード
├── 05-state-rendering/      # Chapter 5のサンプルコード
├── 06-hooks/                # Chapter 6のサンプルコード
├── 07-custom-hooks/         # Chapter 7のサンプルコード
├── 08-architecture/         # Chapter 8のサンプルコード
└── 09-ecosystem/            # Chapter 9のサンプルコード
```

## 🚀 使い方

各章のディレクトリに移動して、以下のコマンドでサンプルコードを実行できます：

```bash
cd examples/XX-chapter-name
npm install
npm run dev
```

## 📝 注意事項

- 各サンプルコードは独立したプロジェクトとして動作します
- Node.js 18以上が必要です
- 実際にコードを動かしながら学習することを推奨します
