## 🚀 使い方

### 1. 演習問題に取り組む

まず、`problem/` ディレクトリの演習問題に取り組みます：

```bash
cd exercises/XX-chapter-name/problem
npm install
npm run dev
```

### 2. 解答例を確認する

演習が完了したら、`solution/` ディレクトリで解答例を確認します：

```bash
cd exercises/XX-chapter-name/solution
npm install
npm run dev
```

## 📝 学習の進め方

1. **まず自分で考える** - 問題文を読んで、自分で実装してみる
2. **動かして確認** - 実装したコードを実際に動かして動作確認
3. **解答例と比較** - 自分の実装と解答例を比較して学ぶ
4. **理解を深める** - なぜその実装が良いのか理解する

## 💡 ヒント

- すべての演習問題は、対応する章の内容で解けるように設計されています
- 分からない場合は、まず該当章のドキュメントを読み直しましょう
- 解答例は一例です。他の実装方法も考えてみましょう
